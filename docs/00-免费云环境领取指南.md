# 免费云开发环境领取指南

> 适用场景：微信开发者工具点击「云开发」后，开通页面只有 19.9 元付费套餐，没有免费选项。
>
> 结论：**先不要在这个页面付款。** 2026 年起微信云开发的免费环境不再由开通页直接提供，改为通过「AI 小程序成长计划」发放。

---

## 一、为什么开通页看不到免费选项

微信云开发当前采用「基础套餐 + 按量付费」模式，开通页默认展示的是付费套餐：

| 套餐 | 价格 | 配额 |
| --- | --- | --- |
| 个人版（连续订阅） | ¥19.9 / 月，自动续费 | 40000 资源点 / 月 |
| 单月 | ¥19.9 / 月，不自动续费 | 40000 资源点 / 月 |

免费资源通过两条独立通道发放，都不在这个开通弹窗里：

1. **开发阶段免费体验环境**：小程序未发布上线前可免费用，配额等同基础套餐。
2. **AI 小程序成长计划**：报名后免费获得一个 **6 个月有效**的个人版环境，并附赠混元大模型 Token 与生图额度。

第二条是目前最稳妥、最容易拿到的路径，也是本文重点。

---

## 二、报名前的唯一硬性检查：小程序类目

进入微信公众平台（https://mp.weixin.qq.com/），登录后查看左侧菜单是否有「**行业能力**」。

- 能看到「行业能力」→ 继续第三步。
- 看不到，或点进去后「参与计划」按钮是灰的 → 先改类目。

**类目要求**：必须属于**文娱、工具、社交、深度合成、资讯**这类虚拟工具与服务。线下实体行业类目不在扶持范围内。

修改路径：微信公众平台 → 设置 → 基本设置 → 服务类目 → 修改。

本项目「铁路旅客互助平台」建议选择「**社交 - 社区/论坛**」或「**工具 - 效率**」，二者都在扶持范围内。

> 类目修改后通常即时生效，但成长计划入口可能有缓存，重新登录后台再看一次。

---

## 三、报名成长计划

1. 微信公众平台 → 左侧「**行业能力**」；
2. 找到「**AI 小程序成长计划**」入口，点「**参与计划**」；
3. 按页面提示选择领取方式。此时**尚未创建云开发环境**，应选择「没有云开发环境」这一档，对应权益是：
   - 免费获得 **6 个月有效**的个人版环境；
   - 附赠 AI 资源包（2026 年二期：10 亿 Token、10 万张生图额度）；
4. 按引导完成领取，可能需要跳转腾讯云账号登录并确认。

> 一个小程序账号只能参与一次该活动，领取后不可重复。

---

## 四、回到开发者工具开通环境

报名成功后，回到微信开发者工具：

1. 点顶部「云开发」；
2. 新建环境，环境名称填 `tonglu-dev`（小写字母、数字、短横线，字母开头）；
3. 套餐选择处应出现免费或已抵扣的选项；
4. 若仍显示 ¥19.9，先看页面下方「**代金券**」一栏——报名成功后会有一张云开发代金券，选择使用即可；
5. 环境创建完成后，复制**环境 ID**（形如 `tonglu-dev-3gxxxxxxx`）。

### ⚠️ 关于自动续费

开通页默认选中的是「**个人版（连续订阅）**」，会自动扣款续费。若最终仍需付费，务必改选「**单月**」，避免忘记取消而被持续扣费。

学生团队预算有限，这一点务必在付款前确认。

---

## 五、把环境 ID 填进项目

编辑 `miniprogram/config.js` 第 1 行：

```js
const CLOUD_ENV_ID = 'tonglu-dev-3gxxxxxxx';
```

保存后重新编译。

---

## 六、验证是否真正接通

1. 云开发控制台 → 数据库 → 新建集合 `users`；
2. 左侧 `cloudfunctions` → 右键 `login` → 「上传并部署：云端安装依赖」；
3. 开发者工具点「编译」，切到「我的」tab；
4. 回云开发控制台 → 数据库 → `users`，应出现一条记录，字段含 `nickname: "旅者"`、`creditScore: 60`。

看到这条记录，说明前端 → 云函数 → 数据库全链路已通。

---

## 七、如果最终仍然拿不到免费环境

按优先级排列的备选方案：

| 方案 | 成本 | 说明 |
| --- | --- | --- |
| 继续用本地演示数据开发前端 | 0 元 | 项目 `utils/cloud-api.js` 自带 mock 兜底，界面和交互可以先做完，后端延后接 |
| 单月付费 19.9 元 | 19.9 元 / 月 | 只在需要验证真实链路时开一个月，用完即停 |
| 换其他免费后端 | 0 元 | 需要改代码，工作量大，零基础团队不建议 |

对于大创项目，推荐组合：**前端先用 mock 数据推进，等免费环境审批下来再接后端**。这样不会阻塞进度。
